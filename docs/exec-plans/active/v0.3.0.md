## Phase 3: Seed script

### Step 7: `cmd/seed` binary
HTTP-based seeder that exercises the full path (API → Kafka → Worker → Receiver).

- [ ] Write `cmd/seed/main.go` with flags:
  - `--api string` (default `http://localhost:8080`)
  - `--events int` (default 50)
  - `--subs int` (default 3): number of subscriptions to create
  - `--receiver string` (default `http://receiver:9000` / `http://localhost:9000`)
  - `--scenario string`: `normal` | `retry` | `circuit-break`
- [ ] Scenarios:
  - `normal`: create N subs pointing at receiver (no fail rate), send events
  - `retry`: create subs, set `--fail-rate 0.7` on receiver via API or env, send events
  - `circuit-break`: send enough failures to trip circuit breaker, observe recovery
- **Verify:** `go run ./cmd/seed --scenario normal --events 20` creates subscriptions and events visible in DB and Grafana
