## Phase 1: Fix test infrastructure

### Step 1: Corrigir schema incompleto no helper de testes do postgres

O `setupTestDB` em `batcher_test.go` cria um schema parcial — faltam colunas
em `events` (`last_error`, `delivered_at`) e a tabela `delivery_attempts` inteira.
Testes de `event.go` vão falhar por erro de schema antes de chegar na lógica.

Solução: criar `testhelper_test.go` em `package postgres` que sobe PostgreSQL via
testcontainers e aplica as migrations reais do projeto (em vez de DDL inline).
Isso garante que o schema de teste sempre reflete o schema de produção.

- [ ] Criar `internal/repository/postgres/testhelper_test.go` com `setupIntegrationDB`
      que aplica migrations de `migrations/` via `golang-migrate` ou SQL direto
- [ ] Verificar que o `batcher_test.go` existente continua passando com o novo helper
- **Verify:** `go test ./internal/repository/postgres/... -v -run TestBatcher` passa
